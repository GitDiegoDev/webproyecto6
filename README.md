# Gestor de Cobranzas

Aplicación web sencilla, moderna y responsive para asistir en la gestión diaria de cobranzas de una financiera de forma complementaria y personal.

## Documentación

El documento maestro del proyecto se encuentra en [docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md). Contiene todas las especificaciones funcionales, reglas de negocio, stack tecnológico y fases de desarrollo sugeridas.

## Stack Tecnológico Objetivo

- **Backend:** PHP 8.3+ con Laravel 11+
- **Database:** MySQL
- **Frontend:** Blade, Livewire, Tailwind CSS, Alpine.js (para interactividad menor)
- **Importaciones:** PhpSpreadsheet para archivos Excel (`.xlsx` / `.csv`)
- **Testing:** PHPUnit o Pest

## Estado del Repositorio

El proyecto se encuentra en la etapa inicial de preparación y planificación. No se ha inicializado el framework Laravel ni la base de datos para permitir un análisis completo y estructurado antes de realizar cambios de arquitectura importantes.
